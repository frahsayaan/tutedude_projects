This program demonstrates how Python lists and tuples work.

A list is mutable, so items can be added or changed.
A tuple is immutable, so its values cannot be directly changed.
append() adds one item to the end of a list.
extend() can add multiple items.
List indexing starts from 0.
Negative indexing can be used to access items from the end.
A tuple can be converted to a list using list().
A list can be converted back to a tuple using tuple().
type() is used to check the data type of a variable.

Why not give two arguments?

This would be incorrect:

products.append("Cup", "Microwave")

because append() is designed to add one object/item at a time.
